# Component List

The following table lists the primary hardware components used in the AI-Based Biomedical Waste Segregation Robotic Arm.

| Component | Quantity | Purpose |
|-----------|---------:|---------|
| ESP32 Development Board | 1 | Main embedded controller |
| USB Camera | 1 | Image acquisition for AI detection |
| PCA9685 Servo Driver | 1 | PWM control for multiple servos |
| Servo Motors | 6 | Robotic arm movement |
| Robotic Gripper | 1 | Object gripping mechanism |
| External DC Power Supply | 1 | Powers the robotic arm |
| Breadboard / PCB | 1 | Circuit implementation |
| Jumper Wires | As Required | Electrical connections |
| Mechanical Links | Multiple | Robotic arm structure |
| Bearings and Fasteners | Multiple | Mechanical assembly |
