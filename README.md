# AI-Based Biomedical Waste Segregation Robotic Arm

An intelligent robotic system designed to automatically detect, classify, and segregate biomedical waste using Artificial Intelligence, Computer Vision, and Embedded Systems.

---

## Project Overview

Biomedical waste contains hazardous materials that can pose serious health and environmental risks if not handled properly. Manual segregation exposes healthcare workers to infections and contamination.

This project aims to automate the biomedical waste segregation process using a 6-DOF robotic arm integrated with AI-based object detection and embedded control systems. The robot identifies different categories of biomedical waste, picks them using the robotic arm, and places them into the appropriate disposal containers.

The system combines robotics, embedded systems, computer vision, and IoT technologies to improve safety, accuracy, and efficiency in biomedical waste management.

---

- Automate biomedical waste segregation.
